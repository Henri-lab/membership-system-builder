# 账户合并（account merge）

> 适用分支：`+merge`（后置）。把 source 账户并入 target：权益按**段并集**、积分走**账本转移**、
> 历史不可物理改写、合并不可逆。

## 1. 前置与安全

- source / target 均为本人，需二次验证（短信/邮件）+ 可选冷静期；
- source 无未终结订单 / 退款 / 争议 / 活跃支付意图；
- 合并记录 `(source, target)` 唯一且**不可逆**（MUST 在实现文档声明）。

## 2. 合并语义（OP-M2）

1. **权益段并集**：同 `product_ref` 的权益段取并集——重叠区间取并集端点（`max` 到期），
   永久权益覆盖限期权益。**禁止简单相加**：把两个"还剩 1 个月"的段相加会得到错误的"2 个月"，
   只有不重叠的段才在时间轴上前后相接；
2. **积分走账本**：成对 `transfer` 分录（source 负向 + target 正向，共用同一事件幂等键），
   余额与账本同事务（INV-12/13）；
3. **历史不改写**：订单/发票/凭证历史保持 source 归属，可加 `merged_into` 引用；
4. **金额指纹重绑**：fixed 长租占用重绑 target（INV-27）；
5. **礼物**：限量型库存不动，仅转移所有权记录；
6. **收尾**：source 置 `merged`——禁登录、禁新订单；写审计映射（操作者 + 时间 + 各域转移条目引用）。
   `[EVT] account.merged`

## 3. 不可逆与审计

- 需要"撤销"= 再做一次方向相反的合并，不是回滚；
- 审计记录（INV-24）：合并映射、账本成对分录引用、权益段前后快照、操作者与时间。

## 4. 错误模型

| 代码 | 语义 | 约束 |
| --- | --- | --- |
| `NOT_MERGEABLE` | 前置不满足（有未终结业务 / 未通过确认） | 无副作用 |
| `SELF_MERGE` | source == target | 无副作用 |
| `ALREADY_MERGED` | source 已合并 | 返回终态，不重复转移 |

## 5. 符合性

- 测试向量：T-63（段并集 + 账本转移 + 不可逆）、T-64（重复合并幂等）。
